## 基础任务（60 分）

| 任务 | 分值 | 评分标准 | 满分要求 |
|------|------|---------|---------|

| 任务 2：文本分类 | 20 分 | | |

## 扣分项

| 扣分项 | 扣分 | 说明 |
|--------|------|------|
| API Key 硬编码 | -10 分 | 直接写在代码中（如 `api_key="sk-..."`） |
| 代码无法运行 | -5 到 -20 分 | 根据严重程度扣分 |
| 无运行输出 | -3 分/任务 | 代码没有配套的运行截图或输出 |
| 代码无注释 | -5 分 | 关键逻辑没有注释说明 |
| 抄袭/复制 | -100 分 | 发现抄袭他人代码，该作业 0 分 |

---

## 加分项

| 加分项 | 加分 | 说明 |
|--------|------|------|
| 代码风格优秀 | +3 分 | 变量命名清晰、结构整洁、注释完整 |
| 创新实现 | +3 分 | 在基本要求之外有创意的实现方式 |
| 完整测试 | +2 分 | 包含额外的测试用例或边界情况测试 |

---

## 评分等级

| 总分 | 等级 | 说明 |
|------|------|------|
| 90+ | A | 完成所有基础任务，至少 1 个进阶任务，代码质量高 |
| 80-89 | B | 完成所有基础任务，代码能运行但有小问题 |
| 70-79 | C | 完成大部分基础任务，有部分功能不完整 |
| 60-69 | D | 完成部分基础任务，存在较多问题 |
| <60 | F | 大部分任务未完成或无法运行 |
