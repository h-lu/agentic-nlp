## AI 小专栏 #2: 当 LLM 遇到结构化数据 —— 从"差不多就行"到"必须准确"

### 搜索词: "OpenAI JSON mode structured output function calling 2024 2025"

**数据点 1：Structured Outputs 功能发布**
- 2024 年 8 月 6 日：OpenAI 发布 Structured Outputs 功能
- 确保模型输出严格遵循开发者提供的 JSON Schema
- 两种形式：Function Calling 或 `json_schema` response format

**数据点 2：JSON Mode vs Structured Outputs vs Function Calling**
- JSON Mode：只保证输出有效 JSON，不保证遵循特定 Schema
- Structured Outputs：严格保证 Schema 合规
- Function Calling：用于模型与外部工具/API 交互

**数据点 3：企业应用场景**
- 合同信息抽取：需要精确的字段和格式
- 报表生成：需要结构化数据导出
- API 集成：需要可解析的输出格式
