## 典型错误示例

### 错误 1：CostTracker 没有按 Agent 分组

```python
# 错误示例
def get_summary(self) -> Dict:
    total_cost = sum(self.calculate_cost(m) for m in self.calls)
    return {"total_cost_usd": total_cost}
# 问题：无法知道哪个 Agent 最烧钱

# 正确做法
def get_summary(self) -> Dict:
    by_agent = {}
    for m in self.calls:
        agent = m.agent_name or "unknown"
        if agent not in by_agent:
            by_agent[agent] = {"calls": 0, "cost": 0}
        by_agent[agent]["calls"] += 1
        by_agent[agent]["cost"] += self.calculate_cost(m)
    return {"total_cost_usd": ..., "cost_by_agent": by_agent}
```

### 错误 2：评估器返回随机分数

```python
# 错误示例
def calculate_faithfulness(self, response, context) -> float:
    import random
    return random.random()  # 随机分数
# 问题：评估没有意义

# 正确做法
def calculate_faithfulness(self, response, context) -> float:
    prompt = f"""评估回答是否基于上下文（0-1 分）。
上下文：{context}
回答：{response}
输出：只输出数字分数"""
    result = self.llm.chat.completions.create(...)
    return float(result.choices[0].message.content)
```

### 错误 3：流式输出格式错误

```python
# 错误示例
async def generate():
    yield {"stage": "plan", "data": plan}
# 问题：不是 SSE 格式

# 正确做法
async def generate():
    yield f"data: {json.dumps({'stage': 'plan', 'data': plan})}\n\n"
# 必须是 SSE 格式：data: <json>\n\n
```
