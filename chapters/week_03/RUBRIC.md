## 评分注意事项

### 关于 Embedding 缓存

Embedding API 是按 Token 计费的，重复调用相同文本会浪费成本。本作业明确要求实现缓存机制：
- 使用文件缓存（JSON/pickle）即可满足要求
- 缓存键应包含模型名称和文本内容
- 没有缓存的实现扣 5 分

### 关于相似度测试

6 对测试文本应覆盖三种情况：
- 同义词（如"远程办公"vs"在家上班"）：预期相似度 > 0.7
- 语义相关但不同（如"申请年假"vs"年假天数"）：预期相似度 0.4-0.7
- 完全不相关：预期相似度 < 0.4

如果测试文本选择不合理（如全部都是高相似度），酌情扣分。

### 关于 ChromaDB

ChromaDB 的数据文件（默认 `./data/chromadb/`）不应该提交到 Git：
- 在 `.gitignore` 中添加 `data/chromadb/`
- 没有添加的扣 5 分

### 关于 AI 协作练习

AI 协作练习是可选的，不计入总分，但可以作为加分参考（最多 +3 分）。审查的关键点：
1. chunk_size=10000 太大（推荐 200-500 tokens）
2. 没有 overlap 会导致信息被切断
3. n_results=20 太多，噪音过多
4. 没有相似度阈值，会返回不相关结果
5. Prompt 缺少角色和约束
6. 直接拼接所有文档会超出 context window
7. GPT-4 对于简单问答任务过于昂贵

学生应该发现至少 5 个问题才能获得加分。
