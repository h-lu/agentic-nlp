# Week 02 评分标准

## 总分：100 分 + 20 分加分

---

## 核心任务（75 分）

### Part 1：Prompt 模板库（30 分）

| 评分项 | 分值 | 评分标准 | 满分要求 |
|--------|------|---------|---------|
| **1.1 四要素完整性** | 12 分 | | |
| - 角色定义 | 3 分 | 每个 Prompt 都有明确的角色设定 | ✅ 三个模板都有角色定义 |
| - 任务描述 | 3 分 | 任务清晰、具体、无歧义 | ✅ 任务描述能引导 LLM 做正确的事 |
| - 约束条件 | 3 分 | 有明确的边界和约束 | ✅ 覆盖常见边界情况 |
| - 输出格式 | 3 分 | 格式描述清晰可解析 | ✅ 有具体的格式示例或 Schema |
| **1.2 Pydantic 输出格式** | 10 分 | | |
| - 模型定义 | 4 分 | 使用 Pydantic BaseModel 定义输出结构 | ✅ 三个任务都有对应的 Pydantic 类 |
| - 字段完整 | 3 分 | 字段定义完整，有类型注解 | ✅ 字段覆盖需求，类型正确 |
| - Field 描述 | 3 分 | 使用 Field() 添加字段描述 | ✅ 关键字段有 description |
| **1.3 模板可渲染** | 8 分 | | |
| - YAML 配置 | 3 分 | 模板存储在 YAML 文件中 | ✅ 配置文件格式正确 |
| - PromptTemplate 类 | 3 分 | 类实现完整，能正确渲染 | ✅ render() 方法输出完整 Prompt |
| - PromptLibrary 类 | 2 分 | 支持加载和查询模板 | ✅ get() 和 list_templates() 可用 |

## 扣分项

| 扣分项 | 扣分 | 说明 |
|--------|------|------|
| 缺少四要素任一项 | -5 分/模板 | 角色、任务、约束、格式缺一扣分 |
| Few-shot 示例少于 5 个 | -5 分 | 示例数量不足 |
| 测试样本少于 15 条 | -5 分 | 测试集规模不够 |
| 没有迭代记录 | -5 分 | report.md 缺少迭代历史 |
| API Key 硬编码 | -10 分 | 直接写在代码中 |
| 代码无法运行 | -5 到 -20 分 | 根据严重程度扣分 |
| 无运行输出 | -3 分/部分 | 代码没有配套的运行截图或输出 |
| 代码无注释 | -5 分 | 关键逻辑没有注释说明 |
| 抄袭/复制 | -100 分 | 发现抄袭他人代码，该作业 0 分 |

## 加分项

| 加分项 | 加分 | 说明 |
|--------|------|------|
| 代码风格优秀 | +3 分 | 变量命名清晰、结构整洁、注释完整 |
| 测试集设计合理 | +3 分 | 覆盖各种边界情况，难度分布均匀 |

| 创新实现 | +2 分 | 在基本要求之外有创意的实现 |

## 评分等级

| 总分 | 等级 | 说明 |
|------|------|------|
| 90+ | A | 完成所有核心任务，至少 1 个进阶任务，代码质量高 |
| 80-89 | B | 完成所有核心任务，代码能运行但有小问题 |
| 70-79 | C | 完成大部分核心任务，有部分功能不完整 |
| 60-69 | D | 完成部分核心任务，存在较多问题 |
| <60 | F | 大部分任务未完成或无法运行 |

## 评语模板

### A 级评语
```
作业完成度很高。Prompt 设计体现了工程化思维，四要素完整、格式清晰。
Few-shot 示例覆盖全面，边界案例选择合理。评估流程规范，迭代有数据支撑。
进阶任务展示了深入思考。代码质量高，注释清晰。继续保持！
```

### B 级评语
```
核心任务基本完成。Prompt 四要素齐全，但约束条件可以更具体。
Few-shot 示例数量达标，但边界案例可以更多。
评估流程完整，建议增加更多迭代轮次以观察效果变化。
代码能运行，但注释可以更详细。
```

### C 级评语
```
完成了大部分核心任务，但存在以下问题：
1. 部分 Prompt 缺少约束条件，导致输出不稳定
2. Few-shot 示例覆盖不够全面
3. 测试集规模偏小，难以得出可靠结论
建议：完善 Prompt 设计，扩充测试集，建立系统的迭代流程。
```

### D/F 级评语
```
作业完成度较低，存在较多问题：
1. Prompt 四要素不完整
2. Few-shot 示例数量不足
3. 测试集规模不达标
4. 缺少迭代记录
5. API Key 硬编码（严重问题）
建议重新学习本章内容，理解 Prompt Engineering 的核心原则。
如有困难，请及时与助教沟通。
```
