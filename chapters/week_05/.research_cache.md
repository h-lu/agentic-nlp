## 技术查证 (Context7)

### OpenAI Function Calling API
- 最新支持 `pydantic_function_tool()` 和 `chat.completions.parse()` 进行类型安全的工具调用
- 核心循环: 调用 LLM → 检查 tool_calls → 执行工具 → 反馈结果 → 循环

### ReAct Agent Pattern (LangChain)
- 核心模式: Thought → Action → Observation 循环
- Agentic loop: `while tool_calls: execute_tools(); call_llm()`
