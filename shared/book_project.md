# 全书贯穿项目：TextAgent — Agentic 文本分析系统

## 设计理念

每周独立的小练习能让读者获得"当周成就感"，但如果 8 周的内容互不相干，学习会变成碎片。TextAgent 是一条贯穿全书的"超级线"：你从 Week 01 开始，逐周把一个 LLM 应用打磨成**可扩展、可评估、可部署**的 Agentic 文本分析系统。

它解决一个真实需求：**从"会用 API"到"能做系统"**。

本书的总原则是：AI 可以帮你写代码，但只有你能对"架构是否合理、评估是否完善、成本是否可控"负责。

---

## TextAgent 的交付物（权威输出）

- `report.md`：每周迭代一次的项目报告（必须可读、可审计）
- `report.html`：可选的展示版（由脚本从 Markdown 导出）
- 完整代码库：可一键运行、可测试、可部署

> 报告应当由代码生成，记录每次迭代的设计决策和评估结果。

---

## 每周推进清单（建议）

### Week 01：项目初始化 + LLM 调用层

- 搭建项目结构（src/、tests/、docs/）
- 封装统一的 LLM Client 类
- 实现基础的文本分析功能（分类、摘要、抽取）
- 生成最小可用 `report.md`：项目概述、技术选型、初步评估

### Week 02：Prompt 模板库 + 评估框架

- 设计文本分析的 Prompt 模板库
- 实现 Few-shot 示例管理
- 搭建简单的效果评估流程
- 记录：Prompt 迭代历史和效果对比

### Week 03：RAG 基础能力

- 构建文档知识库
- 实现文本切分和 Embedding
- 集成向量数据库（ChromaDB/FAISS）
- 实现基础检索流程

### Week 04：高级 RAG + 评估

- 实现混合检索（向量 + 关键词）
- 添加重排序模块
- 集成 RAGAS 评估
- 记录：不同配置的效果对比

### Week 05：Agent 能力

- 封装文本分析工具（Function Calling）
- 实现 ReAct 模式的 Agent
- 添加工具调用日志
- 完成复杂多步骤任务

### Week 06：多智能体 + Agentic RAG

- 设计多智能体架构（规划者-执行者-审核者）
- 实现 Agent 协作流程
- 集成 Agentic RAG（Agent 自主检索）
- 添加 Human-in-the-Loop 机制

### Week 07：评估 + 优化 + 部署

- 搭建完整的评估流水线
- 实现成本监控与告警
- 部署 API 服务（FastAPI）
- 添加可观测性（Trace、日志）

### Week 08：终稿 + 展示

- 整合所有模块为端到端系统
- 收敛成终稿 `report.md`，并导出 `report.html`
- 准备展示材料（系统架构、演示、业务价值）
- 完成文档和部署指南

---

## 写作与代码协作规则

1. **增量修改**：每周在上周基础上改，不从头重写。
2. **可复现优先**：系统可运行之外，必须能在新机器上一键跑出同样结果（固定依赖版本、记录配置、提供 Docker）。
3. **评估驱动**：每次修改都要有评估结果支撑，记录"改了什么、为什么、效果如何"。
4. **章内必须有 `## TextAgent 进度`**：解释本周对系统做了什么改动，以及为什么这一步跟本周知识点强相关。
5. **业务导向**：每个技术选择都要回答"对业务有什么价值"。
